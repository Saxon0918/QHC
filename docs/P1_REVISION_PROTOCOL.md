# P1 修订实验协议：从投影可辨识性到候选、谱特征与联合选择

**状态：研究设计与数学验收标准。** 本文把已证明的代数事实、带假设的统计识别命题和待验证的预测假设分开。新增模型尚无真实数据增益结论。原 P1 的测试窗口已经参与提出本方案，因此在这些窗口上运行的新方法只能报告为**探索性**；确认性结论需要预先锁定方案后的新时间段或独立来源。

本协议综合 `docs/RESEARCH_PLAN.md`、第一批 P1 结果以及 `Quantum_Hypergraph_P1_Revision_Theory_and_Research_Roadmap.md` 中可检验的谱特征和搜索思路。现有 P1 的名称和结果不重定义：旧 `Q4_random_phase`、`C4_short_time_only` 保持原意；新组谱特征分别称 `Qvol`、`Qcorr`、`Qspec`，形式匹配的经典对照称 `Cmatched`。

## 1. 问题、观测协议和已知事实

对图/时间窗 $g$，令 $T_g$ 为去重后的真实成员集合，$A_g$ 为无噪声二值 clique 投影。主任务是在**同一个测试窗**观察 $A_g$，从独立训练窗的超边标注学习规则，输出 $\widehat T_g$；这不是预测未来事件。测试窗的真超边只在固定候选、模型、阈值之后用于评价。若加入当前窗的成对计数、更多时间快照或节点属性，必须标为另一输入协议，所有对照方法同时获得这些信息。

旧协议每个来源有四个训练窗、一个验证窗、三个测试窗；候选大小 $2,\ldots,5$，每窗返回预算 150，Hamiltonian 为缩放的归一化 Laplacian，时间网格已核实为 ${0.25,0.5,1,2,4,8}$。五种子 Q3−C0 的 AP 差为 Enron $+0.00257\pm0.03467$、高中接触 $-0.00119\pm0.00691$，没有达到原先锁定的 $+0.020$。种子只是相同两来源上的算法稳定性，不能作为五个独立网络。测试候选覆盖分别为 $78/947=0.0824$ 与 $123/4792=0.0257$。证据见 `results/p1-real-sweep-20261113T183830Z/seed_sweep_summary.json` 与 `results/p1-real-20261113T182747Z/sources/source-{0,1}/candidate_coverage.json`。

高中 seed 42 的总体候选 AP 不代表完整恢复：测试候选中 $k=3$ 仅 $18/114$ 为正，$k=4$ 仅 $1/111$，$k=5$ 为 $0/111$。旧池可用于公式复核和旧结果诊断，不能单独支撑“高阶新特征无用”或“高阶新特征有效”的结论。高中参考群组由 20 秒成对接触图的极大团形成，是操作性标签；任何结果都不能自动解释为不可约的真实多人物理事件。

## 2. 数学基础：可证明与不可证明的边界

### 2.1 单张投影的非单射性

无噪声投影定义为

\[
A_{ij}=\mathbf1\{\exists e\in T_g:\{i,j\}\subseteq e\},\qquad i\ne j.
\]

一个三元超边与三条二元超边都生成 $K_3$，甚至二者的每对计数均可为 1。因此 $A$ 的精确解释一般不唯一。若两个潜在解释有同样的 $A$，确定性投影似然对二者相等；测试 $A$ 无法打破二者的先验比。任意 $Z=f(A)$，包括改变 Hamiltonian 或加入 LogDet，仍服从数据处理不等式 $I(T;Z\mid D_{\rm train})\le I(T;A\mid D_{\rm train})$。这不否定某个特征对**受限评分器**的归纳偏置价值，但禁止宣称它从同一 $A$ 创造了新真值信息。

一个有用的充分条件是：若潜在超图同时 *conformal*（投影图每个 clique 被某真实超边包含）且 *Sperner*（真超边互不严格包含），真超边恰为 $A$ 的极大团。训练数据应统计假 clique、嵌套与重叠的频率，用以检验该特殊条件的适用性；聚合多个时间事件的投影通常不满足它。

### 2.2 候选集合给出的硬上界

令 $C_{B,g}$ 为仅用测试可见输入产生、最多返回 $B$ 个去重候选的池，最终 $S_g\subseteq C_{B,g}$。按基数 $k$ 报告

\[
r_{g,k}(B)=\frac{|C_{B,g}\cap T_{g,k}|}{|T_{g,k}|},\qquad
r_g(B)=\frac{|C_{B,g}\cap T_g|}{|T_g|}.
\]

则精确恢复召回不超过 $r_g(B)$，oracle 精确 $F_1\le 2r_g/(1+r_g)$。若设期望完整 $F_1\ge f$，必要条件是 $r_g\ge f/(2-f)$；这只是可行性筛查，绝非保证。高中每测试窗有约 1372–1830 个独特真边，$B=150$ 连理想召回也最多约 8–11%。若希望 50% 召回，单靠计数每窗至少需约 686–915 个返回候选，实际通常更多。Enron 的 $55/947$ 个测试真集合大小超过旧 $k_{\max}=5$，扩大搜索预算也无法触及它们；大小范围与预算上界必须分别报告。

候选 AP 只评价**进入同一个池**的正负例。改变池会改变基率和难度，旧池与新池的 AP 不作横向主结论；跨池首先使用同预算 Recall@Budget、oracle 上界和搜索成本。若以后按每个预算重新训练与选阈值，才可在相同预算/协议下比较完整精确 $F_1$/Jaccard。当前实现仅在 `analysis_budget` 的固定 progressive 池上评价完整恢复，同池内的特征方法才能比较配对 AP、LogLoss 和 Brier。

### 2.3 群组谱特征的确切含义

令 $H=H^\dagger$、$U(t)=e^{-itH}$，对候选 $e$ 取外泄块 $B_e=U_{\bar e,e}$、$G_e=B_e^\dagger B_e$ 与内部保留矩阵

\[
M_e=U_{ee}^\dagger U_{ee}=I-G_e,\qquad0\preceq M_e\preceq I.
\]

旧 Q3 满足

\[
R_{\rm inc}=\operatorname{tr}(M_e)/k,\quad
R_{\rm coh}=\mathbf1^\top M_e\mathbf1/k,\quad
C=R_{\rm coh}-R_{\rm inc}=-\frac2k\sum_{i<j}\operatorname{Re}(G_e)_{ij}.
\]

其中 $k=|e|$，第三列 $C$ 是前两列的精确线性组合。固定 $U$ 后，未归一化的 $kC$ 作为候选成员指示变量的伪布尔函数至多三阶；这是一条**表达形式限制**，尚非性能失败的已证原因。

新特征使用统一正则化 $\widetilde M_e=(1-\varepsilon)M_e+\varepsilon I$：

\[
Q_{\rm vol}(e,t)=-\log\det\widetilde M_e/k,\qquad
Q_{\rm corr}(e,t)=\sum_i\log(\widetilde M_e)_{ii}-\log\det\widetilde M_e\ge0.
\]

`Qspec` 再加入 $\operatorname{tr}(G_e^2)/k,\operatorname{tr}(G_e^3)/k$ 与预先锁定的多时间网格。以上矩阵恒等式、正定性与 Hadamard 不等式可用单测验证；“能够更好地判别真超边”是待验证假设。$Q_{\rm corr}>0$ 可以完全来自群组里**仅一对成员**的相关性，不能单凭它声称不可约的 $k$ 阶关系。原始 $\det M_e=|\det U_{ee}|^2$ 还有候选—补集对称性 $D(e)=D(V\setminus e)$，应纳入反例检查。

令 $J=H_{\bar e,e}$。当 $H$ 实对称且 $t\to0$ 时，

\[
Q_{\rm vol}=\frac{(1-\varepsilon)t^2}{k}\|J\|_F^2+O(t^4),\qquad
Q_{\rm corr}=(1-\varepsilon)^2t^4
\sum_{i<j}|(J^\dagger J)_{ij}|^2+O(t^6).
\]

因此必须提供直接可计算的经典特征 $\|J\|_F^2/k$ 和 $\sum_{i<j}|(J^\dagger J)_{ij}|^2$，以及匹配的热核/波核 Gram、LogDet 统计。旧 C0 已包含共同邻居、边界和 Q3 的短时系数，不能把这些重新命名为一个较强的新 C1 来削弱旧基线。$U=\cos(tH)-i\sin(tH)$ 还可被经典实谱滤波器精确计算；任何优势只能相对于**预先指定、同等预算**的经典特征类陈述，不能称作量子加速或新观测信息。

## 3. 实验轨道与顺序

### 轨道 A：候选支持集，先于评分结论

1. 冻结原 P1 配置、哈希、种子和结果。旧 150 池保留为诊断对照。候选大小上限 $k_{\max}$ 由**训练/验证**真边基数分布和计算预算预先决定，并记录该范围导致的固有遗漏。
2. 在无噪声协议中用共同邻域 $\mathcal N_{\rm ext}(e)=\bigcap_{v\in e}N_A(v)\setminus e$ 扩展 clique。先测可行时完整枚举低基数团的规模，随后以多起点 beam/探索处理较大团。保留非极大中间候选；“自己是真边”与“哪个子候选可能通向真边”是不同问题，扩展不仅需要一个 `expand` 标量，还需要对子节点 $e\cup\{u\}$ 排序。
3. 首版搜索只用 C0 或训练窗拟合的经典提议分数。按 $B\in\{150,300,600,1200,2400\}$ 记录返回数、访问数、各基数配额、二元兜底数、唯一候选数、运行时间和内存。配额在训练/验证确定；测试真边不能决定配额或种子。若选定集合必须追加所有普通二元边作投影兜底，它们也须计入各方法**共同的**预算或明确标为另一个相同的选择器输入预算。
4. 主结果是总计及 $k\ge3$ 的 Recall@Budget、oracle $F_1$ 上界及成本。候选提议器以不同随机种子运行只衡量稳定性，节点重编号可检查索引偏差；有硬预算的确定性搜索在对称图上通常不能保证任意置换严格等变，最多要求无并列情形或随机算法的分布等变。

在训练/验证证据足以支持预先选定的 $B,k_{\max}$ 后，冻结新的共同候选池生成协议。所有后续评分变体必须逐行使用相同池。新池改变了候选基率，旧池的逻辑回归参数、阈值和概率不能直接移植；训练窗须按新提议器重新构造样本并重新拟合。

### 轨道 B：固定新候选池上的表征归因

至少比较 `C0`、`C0 + direct Gram moments`、`C0 + matched classical spectral Gram`、`C0 + old Q3`、`C0 + Qvol/Qcorr/Qspec` 以及 `C0 + Q3 + Qspec`。每个变体使用同一图、候选、标签、训练/验证/测试划分和相同评分器家族；报告输入维数、调参预算和真实运行成本。当前 runner 的额外假 clique 诊断硬匹配 $k$，尝试匹配节点平均度分箱；候选来源在同一 progressive 池中恒定，不能称为来源匹配，度不足时还会回退到仅基数匹配。未来可增加候选边界匹配，避免总体 AP 被大量二元边主导。

当前实现的时间网格与正则化 $\varepsilon$ 由配置预先固定，验证集选择评分器超参数、独立阈值和 Top-$M$；若以后扩大时间网格或 $\varepsilon$ 的搜索，也只能在训练/验证集选择。测试报告配对 AP 差、held-out LogLoss、Brier、分基数 AP、正例基率和强经典对照。旧阈值 $+0.020$ AP 可作为预先锁定的候选判别实质差异；任何修改须在**新确认性测试前**固定。若旧 150 池的高阶正例太少，可另设按 $k$/拓扑匹配的标注机制样本，但它只能诊断机制，不能冒充可部署的完整恢复性能。

### 轨道 C：固定池上的完整结构选择与训练先验

当前 runner 在同一个 `analysis_budget` 候选池上执行独立阈值、验证集确定的 Top-$M$、纯覆盖贪心和不使用候选概率的两部分 MDL 贪心。其 MDL 编码**条件于已知固定节点数 $n$、节点编号及二值图协议**：编码选中集合，再编码未解释的正普通边；这是明确可解码的选择准则，不是跨不同 $n$ 的完整无条件编码，也不是全局最优求解。条件结构能量与严格贝叶斯 MAP 属于后续分支，当前 runner 不执行。纯覆盖

\[
F(S)=\sum_{p\in E(A)}w_p\mathbf1\{p\in\cup_{e\in S}E(e)\},\quad w_p\ge0
\]

是单调子模的；$1-1/e$ 贪心保证仅适用于纯覆盖加基数约束，**不能**推广到加入评分、MDL 或重叠惩罚的完整目标。覆盖/MDL 对投影歧义没有唯一性保证，尤其可能删去投影上冗余但真实存在的嵌套或重叠超边。

更有统计解释的一条支路从独立训练事件建立发生先验。若 $N_{e,t}\mid\lambda_e\sim\operatorname{Poisson}(\Delta_t\lambda_e)$、$\lambda_e\sim\operatorname{Gamma}(a_k,b_k)$，并假设不同候选 $e$ 的 $\lambda_e$ 在给定**固定**超参数时相互独立、各边的事件过程在给定发生率后相互独立，训练后 $a'_e=a_k+\sum_{t\in\mathrm{train}}N_{e,t}$、$b'_e=b_k+\sum_{t\in\mathrm{train}}\Delta_t$，新窗事件出现先验为

\[
\pi_{e,\rm new}=1-\left(\frac{b'_e}{b'_e+\Delta_{\rm new}}\right)^{a'_e}.
\]

这一支路要求事件计数、可解释的窗口时长、相同成员身份和近似平稳率；共享的随机超参数若被积分掉，各候选的边存在变量通常不再独立，下面的乘积式便不成立。若只有去重存在标签，应改用 Bernoulli/cloglog 模型，不得捏造计数。给定真正不使用当前 $A$、且在上述条件下跨候选独立的先验，再**显式固定一个候选宇宙** $\mathcal C$，精确投影的条件分布为

\[
P(z\mid A,D_{\rm train},\mathcal C)\propto
\mathbf1\{\operatorname{Proj}(z)=A\}
\prod_{e\in\mathcal C}\pi_e^{z_e}(1-\pi_e)^{1-z_e}.
\]

这只是**给定 $\mathcal C$ 内的候选存在变量**的后验；它不能代表宇宙外真实超边的不确定性。候选不完备时这一分布可能无可行支持；必须在同一显式宇宙中计入兜底二元边，或另行声明噪声似然。若候选评分 $p_e$ 已使用当前 $A$，再同投影损失组合只能称为**判别式条件能量**，不能把 $A$ 当两份独立贝叶斯证据。现有旧 P1 的 `class_weight=balanced` 逻辑回归概率未经自然基率校准，不能直接充作先验 odds；新 runner 虽使用 `class_weight=null`，仍须先检查 Brier/LogLoss 及校准，不能直接赋予概率模型解释。

当前输出报告精确超边 Precision/Recall/$F_1$/Jaccard、嵌套边和真实时间窗中未见成员组合的召回、投影误差与运行时间。后验歧义的量化仅属于未来具备有效概率模型和明确候选宇宙的分支，当前结果不包含它。最小有意义 $F_1$ 差异必须在新测试前预注册。结构选择与量子特征的组合只在各自独立消融有证据时进入确认性比较。

### 轨道 D：多时间联合观测的条件性识别，单列协议

这是与单张 $A$ 的表征实验不同的科学问题。假设有大量等长、可比较且条件独立的窗口，群组事件数满足 $N_{e,t}\sim\operatorname{Poisson}(\Delta\lambda_e)$，且最大真群组规模 $K$ 已知或可控。对普通边集合 $J$ 定义

\[
F(J)=-\Delta^{-1}\log P(A_{p,t}=0\ \forall p\in J)
=\sum_{e:\exists p\in J,\,p\subseteq e}\lambda_e.
\]

若不同普通边 $p_1,\ldots,p_r$ 的端点并集为 $V$，容斥给出

\[
S(V):=\sum_{e\supseteq V}\lambda_e
=\sum_{\varnothing\ne J\subseteq[r]}(-1)^{|J|+1}
F(\{p_j:j\in J\}).
\]

在所有可能非零群组包含于已声明有限支持、且能稳定估计相应 $S(V)$ 时，可由大到小作 Möbius 反演 $\lambda_V=S(V)-\sum_{e\supsetneq V}\lambda_e$。这是一条**条件性总体发生率识别命题**，不保证判定某一单独测试窗的真实事件。若允许成对计数这一**新输入**，则不同 dyad 的协方差还满足 $\operatorname{Cov}(Y_{ab},Y_{ac})/\Delta=\sum_{e\supseteq\{a,b,c\}}\lambda_e$，但共享活跃度也可制造伪相关，必须控制。

当前八个不等长窗口不足以可靠估计共同缺边概率；Enron 有 $K>5$，不能直接用五阶截断反演。先在独立 Poisson 合成数据上验证恒等式及反演，再用具有足够独立粗块的新数据检查平稳、等时长、共同活跃度和“同一 $V$ 不同普通边覆盖所得 $S(V)$ 一致”的模型约束。高中数据不能将定义标签的同一 20 秒成对图直接暴露给模型。此轨道的结果与只见单窗二值 $A$ 的主表分开报告。

## 4. 依赖关系、验收与如实的失败分支

| 阶段 | 必要验收 | 允许得出的结论 |
|---|---|---|
| P0：代数与反例 | Q3 Gram、Qvol/Qcorr、短时系数、补集反例、三角歧义通过数学测试 | 代码与公式一致；不等于预测有效 |
| P1-A：搜索 | 在训练/验证选定的相同预算下，报告总体与 $k\ge3$ Recall@Budget、oracle 上界和成本 | 判断搜索是否改善可达支持集 |
| P1-B：特征 | 冻结共同池，Qspec 同直接经典矩和匹配动态核配对比较；高阶正例数量足够 | 判断相对指定经典函数类是否有增量 |
| P2：结构选择 | 只用验证集定权重/阈值，完整精确 $F_1$/Jaccard、校准和歧义一起报告 | 判断联合推断是否改善完整恢复 |
| 确认 | 在未用于提出本方案的新来源/时间段按锁定配置运行 | 才可提出新的泛化效果主张 |
| 时间识别 | 足量等长可比窗、模型约束检查和合成已知真值检验 | 仅在条件成立时讨论群组发生率识别 |

如果候选覆盖无提升，回到搜索/可恢复性假设；如果 Qspec 的收益被直接经典矩或热/波 Gram 解释，如实报告量子机制的负结果；如果联合选择只提高投影覆盖而不提高精确超边指标，停止把覆盖当作恢复证据；如果时间模型不满足平稳/独立/样本量条件，不执行真实强度反演。

## 5. 运行与报告约定

预期分阶段入口为 `python main.py p1-revision --config configs/p1_revision_smoke.yaml`（合成工程与数学检查）和 `python main.py p1-revision --config configs/p1_revision.yaml`（服务器真实实验；修订配置指向基础真实数据协议）。这两条命令的存在及具体输出应以代码最终实现与 README 为准；本协议不把尚未运行的服务器实验写成结果。本机若缺少 `data/raw`，只能运行合成测试和旧结果审计，不能虚报真实数据新方法性能。

每次运行保存配置/时间边界/输入哈希/代码版本、各候选池及分层覆盖、候选标签基率、逐方法种子级预测、校准与完整集合指标、各阶段时间和来源级采样 RSS 峰值，并记录所有失败和未满足条件。当前各预算搜索分别独立运行，报告的搜索时间是各自的完整运行成本；RSS 采样不提供每个特征阶段的峰值。合成图的节点编号跨独立种子没有共同成员身份，因而 `train_unseen` 只对真实时间窗报告。确认性 Gate 必须写明使用了哪些独立来源；同一来源五个种子不作为五个独立复现。
